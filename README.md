#### 🧠 [NoteFlow — Cross-Platform AI Note Management with Advanced RAG](https://github.com/IvanTran0101/note_ai_app)

Cross-platform, offline-first note app with secure collaboration, AI summarization, and an advanced retrieval-augmented question-answering system. ⭐ *My favorite project — the direction I want to grow into.*

- 🔍 **Advanced RAG pipeline** — hybrid semantic vector search + BM25 keyword retrieval, Reciprocal Rank Fusion, MMR diversification, context expansion, and token-budgeted evidence assembly
- 🤖 **LLM stack on AWS** — Cohere multilingual embeddings via Amazon Bedrock, Amazon S3 Vectors for retrieval, event-driven indexing with DynamoDB Streams + Lambda
- 🛡️ **Grounded, verified answers** — JEV (TypeSafe System One) pre-generation evidence verification for answerability & contradictions, evidence-based refusals, source citations validated against note ownership, permissions, consent, and revisions
- 📝 **AI summarization** — direct summarization for short notes, section-summary-merge for long notes; cloud DeepSeek inference alongside an on-device llama.cpp/GGUF implementation
- ⚡ **AWS serverless backend** — Cognito auth, API Gateway, Lambda, DynamoDB, S3 & AppSync: offline-first sync, attachments, access-controlled sharing, real-time updates

<sub>Flutter · Dart · TypeScript · AWS Amplify Gen 2 · Lambda · API Gateway · Cognito · DynamoDB Streams · S3 · S3 Vectors · Bedrock · Cohere Embed v3 · JEV · DeepSeek · llama.cpp · GGUF</sub>
